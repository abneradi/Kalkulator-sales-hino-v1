KALKULATOR HINO LUBUKLINGGAU — PROJECT BARU
Periode data harga: Oktober–Desember 2026

FITUR
- HINO 300 / HINO 500
- Pilih karoseri dan plat Hitam/Kuning
- Harga OFF: SPV / BM / Harga Tengah
- Harga Tengah = (SPV + BM) / 2, dibulatkan ke Rp500.000
- BBN otomatis sesuai data
- ON Nett, Pricelist, OTR, Diskon Dealer
- OTR Leasing
- Diskon DP = OTR Leasing - ON Nett
- TDP input dan DP Setor = TDP - Diskon DP
- Simulasi Hino Finance (HFI) dan Indomobil Finance (IMFI)

DEPLOY VERCEL VIA GITHUB
1. Buat repository GitHub baru.
2. Upload SEMUA isi folder ini ke repository (bukan file ZIP-nya).
3. Di Vercel pilih Add New > Project.
4. Import repository GitHub tersebut.
5. Framework: Other / kosongkan framework preset jika diminta.
6. Klik Deploy.

UPDATE BERIKUTNYA
Cukup replace file data.json / script.js / style.css / index.html yang berubah di GitHub, lalu commit. Vercel akan auto-deploy jika repository sudah terhubung.

CATATAN
- Harga chassis/pricelist mengikuti daftar harga Hino Oktober–Desember 2026 yang tersedia.
- Jika suatu harga tidak tersedia pada sumber, aplikasi menampilkan “Tidak tersedia”, bukan membuat angka sendiri.
- Rumus leasing adalah template kalkulator dan hasil final tetap mengikuti quotation/approval leasing.
